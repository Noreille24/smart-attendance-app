# smart-attendance-app

Final Project for CS411 Human Computer Interaction

18. Smart Attendance Interface

Main User:
-Teacher, Students

Prototype Type
-Web/Mobile

Description
A redesigned attendance interface system that makes attendance recording easier for students and instructors.

Features
-Student Login
-Attendance Status
-Class Schedule
-Attendance History
-Instructor Dashboard
-Reports

HCI Focus
Students should investigate how to reduce errors in attendance recording.
